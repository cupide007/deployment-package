# 安提斯特虚拟国 - 部署指南

## 1. 环境要求
* **服务器**：支持 PHP 7.4 或更高版本。
* **数据库**：本系统使用 Flat-file (纯文件) 数据库引擎，**不需要** MySQL/MariaDB。数据将直接存储在服务器的 `retinbox-main` 目录中。
* **权限**：Web 服务器 (如 Nginx/Apache 的运行用户) 必须对项目根目录及 `retinbox-main` 目录拥有 **读写权限**。

## 2. 安装步骤

1.  **上传文件**：
    将 `deployment-package` 文件夹内的所有文件上传至服务器网站根目录。

2.  **设置权限 (关键)**：
    确保 PHP 进程有权限在根目录下创建和写入文件夹。
    * *Linux 示例*: `chmod -R 755 .` (如果上传者是 www-data 则不需要，否则需 `chown`)。

3.  **系统初始化**：
    * 在浏览器访问网站首页 `index.html`。
    * 系统会自动检测数据库状态。如果是首次运行，会自动创建数据库并生成默认管理员。
    * **默认管理员账号**：
        * 账号：`admin`
        * 密码：`test`

4.  **安全检查**：
    * **强烈建议**：登录后立即在“用户中心”修改管理员密码。
    * **删除测试文件**：上线前请务必删除 `comprehensive-test.html`。

## 3. 常见问题
* **无法上传图片/文件**：检查 `users/` 和 `library/` 目录以及 PHP 的临时目录是否有写入权限。
* **数据丢失**：由于是文件数据库，请定期备份自动生成的 `retinbox-main` 文件夹。
* **404 错误**：确保 Web 服务器配置正确，能够解析 `.php` 文件。
