Retinbox Deployment Manifest (PHP Edition)

1. 环境要求
Web 服务器: Nginx 或 Apache
PHP 版本: 7.4 或更高
PHP 扩展: php-json, php-mbstring
数据库: 本项目使用基于文件的 KV 数据库

2. 部署步骤
1. 将所有文件上传至 Web 服务器根目录。
2. 确保以下目录存在并具有写入权限 (755 或 777):
   - /database/
   - /uploads/avatars/
   - /uploads/documents/
3. 访问 /init.php 进行系统初始化。

3. 目录结构说明
- /auth/       : 登录注册接口
- /bank/       : 银行系统接口
- /users/      : 用户管理接口
- /library/    : 图书馆接口
- /admin/      : 后台管理接口
- /common.php  : 核心配置文件
- /retinbox-config.js : 前端 API 配置文件

4. 常见问题
- 如果上传文件失败，请检查 /uploads/ 目录权限。
- 默认管理员: admin / test
